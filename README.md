# Quizzty 🧠

Une application mobile de Quiz moderne, fluide et élégante réalisée avec Flutter.

## Fonctionnalités
- **Sélection personnalisée :** Choisissez le nombre de questions, la catégorie, la difficulté et le type de quiz.
- **Traduction à la volée :** Questions et réponses traduites automatiquement de l'anglais vers le français grâce à l'API MyMemory.
- **Support bilingue :** Basculez à tout moment entre l'anglais original et la traduction française à l'aide d'un bouton de bascule dédié.
- **Interface Premium :** Thème moderne Indigo / Slate Blue, mise en page entièrement adaptative et défilante.
- **Effets visuels :** Animation native de confettis/paillettes sur les côtés lors d'une bonne réponse.
- **Clean Architecture :** Séparation stricte Domain / Data / Presentation / UI.

## Installation & Lancement
```bash
flutter pub get
flutter run
```

## Lancer les tests
```bash
flutter test
```
